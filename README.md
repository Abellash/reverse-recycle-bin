# Reverse Recycle Bin (R²B) ♻️🗑️

## Basic Details

### Team Name: Uselessly Useful (U²)

### Team Members

* Team Lead: Abellash C Mathew

### Project Description

**Reverse Recycle Bin (R²B)** is a recycle bin that fundamentally misunderstands its job.

Instead of removing unwanted files and freeing up space, R²B responds to every attempt at recycling by creating **even more useless files** — unnecessary backups, fake reports, pointless documents, fictional research papers, and other digital garbage nobody asked for.

The more you try to clean your desktop, the worse it gets.

### The Problem (that doesn't exist)

Modern computers are becoming dangerously efficient at deleting unwanted files.

Every day, millions of perfectly useless documents disappear forever because people recklessly empty their recycle bins.

What happens when you desperately need:

`Project_Report_FINAL_FINAL_ACTUAL_FINAL.doc`

or

`The_Psychological_Effects_of_Being_a_Spoon.pdf`?

Exactly.

We are facing a severe shortage of digital garbage.

### The Solution (that nobody asked for)

Introducing **R²B — the Reverse Recycle Bin.**

A revolutionary recycling system that follows one simple principle:

> **Why delete one file when you can create twenty more?**

R²B initially disguises itself as a perfectly normal Recycle Bin inside a simulated desktop environment.

Drop a file into it and it politely says:

**"Recycling..."**

But instead of deleting the file, it begins producing more.

And more.

And more.

Every attempt to clean the desktop makes the situation progressively worse.

Eventually, the innocent Recycle Bin reveals its true identity:

## REVERSE RECYCLE BIN™

Saving absolutely no storage since 2026.

### Implementation

R²B runs entirely as a simulated desktop environment in the browser.

Files inside the desktop are **virtual files**. The application does not delete, modify, move, or damage real files on the user's computer.

The virtual filesystem keeps track of files, documents, their contents, desktop positions, and the user's increasingly unsuccessful recycling attempts.

### Installation

```bash
git clone https://github.com/Abellash/reverse-recycle-bin.git
cd reverse-recycle-bin
npm install
```

### Run

```bash
npm run dev
```

Open the local URL displayed by Vite, normally:

```text
http://localhost:5173
```

### Production Build

```bash
npm run build
```

The deployable static site is written to `dist/`.

## How It Gets Worse

R²B remembers how many times the user has attempted to recycle something.

### Attempt 1

A few suspicious copies appear.

```text
Project_Report_FINAL.doc
Project_Report_backup.doc
Project_Report_copy.doc
```

### Attempt 2

R²B becomes concerned that you may be running out of files.

> "You seem to be running low on files. I've helped."

### Attempt 3

The system begins producing completely unrelated documents.

```text
The_History_of_a_Person_Who_Does_Not_Exist.pdf
Q3_Strategic_Potato_Alignment.pptx
Why_Do_Chairs_Exist.pdf
Instructions_For_Operating_A_Spoon.pdf
```

### Attempt 4

R²B develops an emotional attachment to the garbage.

> **STOP DELETING MY CHILDREN.**

### Attempt 5

The truth is finally revealed.

# REVERSE RECYCLE BIN™

The user receives their final sustainability report showing exactly how badly they have failed at recycling.

Possible achievements include:

```text
Files submitted:             5
Files removed:               0
New files generated:        72
Storage saved:         -486 MB
Environmental efficiency: -14,194%
Digital waste created: EXCELLENT
```

Thank you for making the planet considerably worse.
